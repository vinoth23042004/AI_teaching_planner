# AI Teaching Planner

## 📌 Overview

This project is an AI-driven platform designed to automate key academic
processes for teachers and enhance learning experiences for students. It
leverages **Generative AI**, **automated quiz generation**, and an **AI
chatbot** to streamline educational workflows.

## 🚀 Features

### **1. Generative AI for Weekly Lesson Plans**

- Automatically generates **weekly lesson plans** from an uploaded
  syllabus or timetable.
- Uses Generative AI models to understand topics, schedules, and
  learning flow.
- Saves teachers hours of manual planning work.

### **2. Automatic Exam Question Generation**

- Creates exam questions in multiple formats:
  - **MCQs**
  - **2-mark questions**
  - **5-mark descriptive questions**
- Entire question paper creation becomes fully automated.

### **3. Online Quiz Module**

- Converts AI-generated MCQs into a **real-time quiz system**.
- Features include:
  - Instant scoring
  - Live results dashboard
  - Student performance analytics

### **4. AI Chatbot -- Virtual Teaching Assistant**

- Acts as a 24/7 learning assistant for students.
- Provides **instant subject-related answers**.
- Helps clarify doubts, improving learning efficiency.

## 📌 Steps to Run

1. Clone or extract the project files.
2. Install all required Python libraries.
3. Run the **syllabus parser** script to upload and process the
   syllabus/timetable.
4. Run the **Lesson Plan Generator** script.
5. Run the **Question Generator** script to generate:
   - MCQs\
   - 2-mark questions\
   - 5-mark questions
6. Start the **Quiz Module** to enable real-time quizzes and scoring.
7. Run the **AI Chatbot** service to assist users with subject-related
   questions.
8. Access the **dashboard** to view results and analytics.

## 📝 How It Works

1. **Upload Syllabus / Timetable**
   - System parses and extracts topics.
2. **AI Lesson Plan Generator**
   - Creates structured weekly lessons.
3. **AI Question Generator**
   - Produces MCQs, short answers, and long answers using Generative
     AI.
4. **Quiz Engine**
   - Converts MCQs into interactive assessments.
5. **Results Dashboard**
   - Tracks performance and displays analytics.
6. **AI Chatbot**
   - Provides instant academic support.
